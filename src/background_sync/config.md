Use **Tools → Background Sync…** (or the *Config* button) for a friendlier settings window.

- `enabled`: sync automatically in the background (`true` / `false`).
- `interval_minutes`: minutes between syncs (2–240). Default: 5.
- `idle_seconds`: if you are studying when a sync is due, wait until Anki has had no keyboard or mouse input for this many seconds (15–900). Default: 60.
- `show_indicator`: show the cloud status item in the top toolbar.
- `notify_on_error`: show a brief notice when a sync fails (network errors only after 3 failed attempts in a row).
- `notify_on_success`: show a brief notice after every successful sync.

Media follow Anki's own "Sync audio and images too" preference. If AnkiWeb requires a full sync, Anki's usual dialog asks you whether to upload or download.
